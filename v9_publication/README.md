# V9 publication outputs

All numerical tables and figures in this directory are generated from saved V9 or frozen V8 artifacts. Each figure has a 300-DPI PNG, vector PDF, source CSV and source-hash JSON. `v9_traceability_audit.json` verifies the primary V9 prediction, split, checkpoint, calibration, threshold, preprocessing, VAD and encoder lineage. `v9_final_research_audit.txt` reports requested analyses that are complete, unavailable or non-estimable.

The TORGO-only nested experiment is complete for five repeated seeds and 15 physical speakers. Its active-speech pipeline selected a one-second window using the documented fallback after no candidate met 90% recording coverage. The primary head uses a fixed K **within each outer fold**; K is selected from that fold's TORGO inner validation and varies across folds. The all-TORGO deployment lock selected K=20.

**The locked UASpeech benchmark is not estimable under this protocol.** Fifteen of 28 M3 speakers have fewer than 20 eligible one-second active-speech recordings, including several with zero. M2–M8 also fail the same evidence requirement. Accordingly, Table 7–9 performance results and severity figures are absent, and the publication audit fails those items. `tables/supplement_channel_budget_feasibility.csv`, `figures/fig09_m3_fixed_budget_feasibility.pdf`, and `figures/fig11_channel_budget_feasibility.pdf` document why. The official M3 prompt and intelligibility metadata audits remain available in the V9 cache, but no missing prediction is filled or inferred.

TORGO results warrant cautious interpretation. The primary V9 ROC-AUC point estimate exceeds the combined measured-confound baseline, but the paired physical-speaker confidence interval for their difference includes zero. A background-only probe remains predictive. `interpretation.txt` contains the resulting manuscript wording. Historical V8 comparisons are labeled as historical and use different preprocessing and evidence budgets.
