# Dysarthria V10

Open [`dysarthria_10.ipynb`](dysarthria_10.ipynb). The notebook contains the complete V10 code, saved execution results, paper tables, and embedded figure previews. No V10 Python source files are needed.

The notebook can be shared as one file for review. Recomputing the studies requires the project data, frozen V8 reference, model weights, and the project's Python environment. Detailed checkpoints, vector PDFs, and source CSVs remain under `outputs/` and `publication/`.
